#[BUG-001] Error 500 al enviar campo de teléfono con formato internacional (+593)

##Descripción
Al intentar guardar un nuevo registro incluyendo el prefijo '+' en el campo teléfono principal, la API responde con un estado HTTP 500 Unhandled Server Error en lugar de procesar o validar el dato.

##Pasos para reproducir
1. Navegar a '/user/new'.
2. Completar los campos requeridos ('Nombre', 'Apellido', 'Email').
3. En el campo 'Telefono', ingresar '+593991234567'.
4 Hacer clic en el boton *"Guardar"*.

##Comportamiento Esperado
El sistema debe aceptar el formato internacional o, en su defecto, mostrar una validación del cliente/servidor diciendo: "Formato de teléfono no válido".

##Comportamiento Obtenido
La interfaz se congela en estado de carga. En las herramientas de desarrollador (Network Tab), la petición 'POST/api/v1/users' retorna estado '500 Internal Server Error'.

##Información Técnica
- **Severidad:** Alta (Impacta funcionalidad principal de registro)
- **Prioridad:** Alta
- **Entorno:** Staging (Chrome v124 / API Backend v1.2.0)
- **Payload enviado:**
  ```json
  {
    "first_name": "Carlos",
    "last_name": "Mendoza",
    "phone": "+593991234567"
  }
- **Respuesta API:**
  {"error": "QueryFailedError: invalid input syntax for type integer"}
