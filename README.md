# QA Engineer & Software Testing Portfolio

Bienvenido a mi portafolio profesional de **Aseguramiento de Calidad (QA)** y **Pruebas de Software**. Este repositorio recopila artefactos de prueba diseñados bajo estándares **ISTQB**, metodologías ágiles y buenas prácticas de automatización.

---

## 👤 Sobre Mí

**Ingeniero en Tecnologías de la Información y Comunicación (TIC)** enfocado en la calidad del software. Mi formación en ingeniería me permite abordar las pruebas con una comprensión profunda de la arquitectura de sistemas, flujos de datos, bases de datos y desarrollo web/backend.

Especializado en análisis de requerimientos, diseño de casos de prueba bajo estándares **ISTQB**, validación de APIs REST y automatización de pruebas E2E.

- **Título:** Ingeniero en Tecnologías de la Información y Comunicación (TIC)
- **Ubicación:** Ecuador
- **Roles de interés:** QA Engineer / Software Tester / Manual & Automation QA
- **Metodologías:** ISTQB CTFL, Agile/Scrum, BDD (Behavior-Driven Development)

## 🛠️ Stack Técnico y Herramientas

| Categoría | Herramientas y Tecnologías |
|---|---|
| **Gestión y Estrategia** | Test Plans, RTM (Matriz de Trazabilidad), Jira, Markdown |
| **Diseño de Pruebas** | Gherkin (BDD), Casos de prueba tabulares, ISTQB Techniques |
| **Pruebas de API** | Postman, Newman, JSON Schema Validation, REST API |
| **Automatización E2E** | Playwright / Cypress, TypeScript / JavaScript, Page Object Model (POM) |
| **Control de Versiones y CI/CD** | Git, GitHub, GitHub Actions |
| **Bases de Datos & Logs** | PostgreSQL, SQL Queries, Chrome DevTools |
