# Plan de Pruebas: Módulo de Registro y Gestión

1. Alcance (Scope)
  -Dentro del alcance: Validación de campos de entrada, creación de registros en la base de datos,       mensajes de error en interfaz y manejo de duplicados.
  -Fuera del alcance: Pruebas de carga/estrés y pruebas de seguridad avanzadas (Penetration Testing).

2. Tipos de Pruebas a Ejecutar
  - Pruebas Funcionales (Caja Negra)
  - Pruebas de Frontera / Valores Límite (Boundary Value Analysis)
  - Pruebas de Transición de Estados
  - Pruebas de Regresión

3. Criterios de Aceptación / Salida
  - 100% de los casos de prueba de prioridad Alta ejecutados.
  - 0 defectos bloqueantes o de severidad Alta abiertos.
